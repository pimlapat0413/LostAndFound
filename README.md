# Lost & Found Web Project

ระบบแจ้งของหายและรับคืนสิ่งของสูญหายของมหาวิทยาลัย

## โครงสร้างโปรเจกต์ (Separated Architecture)

```text
LostAndFound/
├── frontend/    # Next.js 14 + Tailwind CSS (UI/UX)
└── backend/     # สำหรับพัฒนา Backend API Server ในอนาคตอะ
```

## วิธีการรันส่วน Frontend
```bash
cd frontend
npm run dev
```
เปิดใช้งานที่: `http://localhost:3000`
