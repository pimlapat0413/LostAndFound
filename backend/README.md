# Lost & Found Backend Server (Placeholder)

โฟลเดอร์นี้จัดเตรียมไว้สำหรับพัฒนาส่วน Backend ในอนาคต (เช่น Node.js / Express.js, Python FastAPI, หรือ NestJS)

## โครงสร้างอนาคตที่แนะนำ
- `src/controllers/` - ตัวจัดการ Request/Response
- `src/models/` - Schemas สำหรับ Database (เช่น Mongoose / Prisma)
- `src/routes/` - API Endpoints (/api/items, /api/claims, /api/auth)
- `src/config/` - การเชื่อมต่อ Database และ environment variables
